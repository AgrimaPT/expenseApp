# ExpenseApp – Multi-Branch Restaurant Management System

ExpenseApp is a web-based income and expense management application developed for a restaurant business operating multiple branches. It helps the owner monitor financial performance across branches while allowing managers and staff to manage daily financial activities through separate user accounts.

## Features

### Owner Dashboard
- Access and monitor multiple restaurant branches from a single account.
- Review daily income, expenses and profit across branches.
- Monitor monthly financial performance.
- Track the financial progress of individual branches.

### Manager Dashboard
- Access the assigned branch.
- Review and verify daily income records.
- Verify purchases and expenses.
- Monitor branch-level financial activities.

### Staff Dashboard
- Record daily purchases and expenses.
- Update financial transactions for the branch.

### Financial Management
- Maintain daily income and expense records.
- Calculate daily profit.
- Track monthly financial performance.
- Organise financial data by restaurant branch.

## User Roles

- **Owner:** Overall access to all branches and financial performance.
- **Manager:** Branch-level monitoring and verification.
- **Staff:** Daily purchase and expense entry.

## Technology Stack

- **Backend:** Python, Django
- **Frontend:** HTML, CSS, JavaScript, Bootstrap 5
- **Database:** SQLite
- **Deployment:** AWS EC2, Linux, Gunicorn, Nginx, SSL/HTTPS

## Application Overview

1. Staff record daily purchases and expenses.
2. Managers review and verify branch-level income and purchase records.
3. The application maintains daily income, expenses and profit calculations.
4. The owner monitors individual branches and reviews daily and monthly performance from a central dashboard.
